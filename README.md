# 📡 실시간 네트워크 관제 및 지능형 방어 시스템 (IPS)

이 시스템은 네트워크 트래픽을 실시간으로 감시하고, **PPS(초당 패킷 수)** 통계 분석을 통해 비정상적인 트래픽을 유발하는 **투머치토커(Top Talkers)**를 자동으로 탐지 및 차단하는 차세대 네트워크 보안 도구입니다.

---

## 1. 시스템 작동 방식 및 원리

시스템은 크게 **[수집] → [분석] → [방어] → [시각화]**의 4단계로 작동합니다.

### ① 패킷 수집 (Sniffing)

* `Scapy` 라이브러리를 사용하여 네트워크 인터페이스로 들어오는 모든 패킷(IP, TCP, UDP, ICMP 등)을 실시간으로 캡처합니다.

### ② PPS 및 투머치토커 분석 (Analysis)

* **PPS 통계:** 1초 단위로 유입되는 패킷의 총량을 계산하여 네트워크 부하 상태를 파악합니다.
* **Top Talkers:** 특정 IP가 과도하게 패킷을 발생시키는지 실시간으로 집계합니다.

### ③ 지능형 방어 원리 (IPS Logic)

* **자동 방어:** 사용자가 설정한 PPS 임계치를 초과하는 IP가 발견되면, 시스템이 즉시 해당 IP를 `blocked_db`에 등록합니다.
* **필터링:** 차단 목록에 등록된 IP, 포트, 프로토콜 조합이 탐지되면 해당 패킷의 상태를 즉시 `🚨 위협`으로 분류합니다.

### ④ 실시간 시각화 (Visualization)

* `Streamlit` 기반의 웹 대시보드를 통해 누구나 쉽게 그래프와 표 형태로 현재 네트워크 상태를 관제할 수 있습니다.

## 2. 주요 페이지 구성 및 기능

| 페이지명 | 파일명 | 주요 기능 |
| --- | --- | --- |
| **Main 관제** | `project_main_page.py` | 실시간 패킷 로그 출력 및 위협 탐지 알림 |
| **패킷 항목** | `packet_log.py` | 수집된 패킷의 상세 정보(출발지, 도착지, 바이트 등) 표시 |

| **차단 목록** | `security_ips.py` | **핵심 보안 페이지.** IP/포트/프로토콜 차단 DB 관리 및 자동 방어 설정 |

## 3. 실행 방법 (How to Run)

### 필수 준비물

* Python 3.8 이상 설치
* 필요한 라이브러리 설치: `pip install streamlit scapy pandas`

### 실행 순서

1. 터미널(또는 명령 프롬프트)을 엽니다.
2. 프로젝트 폴더로 이동합니다.
3. 아래 명령어를 입력하여 시스템을 실행합니다.
```bash
streamlit run main1.py

```


4. 브라우저에서 열린 관리 창의 왼쪽 메뉴에서 **"차단 목록"**을 클릭해 자동 방어 기능을 활성화합니다.
5. **"Main"** 페이지에서 `🟢 엔진 시작` 버튼을 눌러 실시간 관제를 시작합니다.

---

## 4. 기대 효과

* **DDoS 방어:** 갑작스러운 패킷 폭증 시 PPS 분석을 통해 공격지를 즉시 식별합니다.
* **보안 가시성:** 단순한 텍스트 로그가 아닌 그래프와 DB 형태의 UI로 보안 현황을 한눈에 파악합니다.
* **맞춤형 차단:** 특정 IP뿐만 아니라 포트와 프로토콜까지 세밀하게 제어하여 정밀한 방어가 가능합니다.
